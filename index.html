01

Video Conferencing App

Problem

Remote teams and students needed a lightweight, browser-based video calling solution without heavy client installs or third-party dependencies.

Solution

Built a real-time peer-to-peer video conferencing application supporting multi-user rooms, live chat, and screen sharing — all directly in the browser using WebRTC and Socket.io for signalling.

Key Features
🎥 Multi-user video rooms 💬 Live in-room chat 🖥️ Screen sharing 🔗 Shareable room links
Tech Stack
React.js Node.js Express.js WebRTC Socket.io MongoDB
💡 What I Learned WebRTC peer connection lifecycle, ICE candidates, STUN servers, and managing real-time bidirectional events with Socket.io at scale.
GitHub
02

Stockify — Stock Market Tracker

Problem

Investors and students tracking stock portfolios had no simple, unified dashboard to monitor real-time prices, trends, and personal watchlists without clunky third-party apps.

Solution

A full-stack stock market tracking app that fetches live price data via a stock market API, allows users to manage personal watchlists, and visualises portfolio performance with interactive charts.

Key Features
📈 Live stock prices ⭐ Personal watchlist 📊 Price trend charts 🔐 User auth (JWT)
Tech Stack
React.js Node.js Express.js MongoDB JWT Auth Stock Market API
💡 What I Learned Third-party API integration, async data polling, chart rendering with JS libraries, and persisting user-specific data with JWT-secured endpoints.
GitHub
03

DigiRecycle — Plastic Collection Tracker

Problem

Municipalities and NGOs running plastic recycling drives had no digital way to track collection points, quantities gathered, or volunteer activity — relying entirely on paper logs.

Solution

A Spring MVC web application built with Java, JSP, and MySQL that allows coordinators to register collection drives, track plastic quantities per location, and manage records — following clean MVC architecture with full CRUD operations.

Key Features
📍 Collection point mapping 📦 Quantity tracking 👥 Volunteer management 📋 Summary reports
Tech Stack
Java Spring MVC JSP MySQL CRUD MVC Architecture
💡 What I Learned Spring MVC architecture, JSP view rendering, MySQL schema design, full CRUD operations, and structuring a Java web app following the Model-View-Controller pattern end to end.
